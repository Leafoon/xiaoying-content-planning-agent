# AI 使用情况

项目中的模型边界分为两层。

1. Mock 模式是离线测试策略，决策基于结构化请求和上一轮工具结果。Trace 明确标记 `mode=mock`，不宣称产生了真实模型结果。
2. Real 模式通过 OpenAI 官方 SDK 的 Chat Completions Tool Calling，将四个工具 schema 交给模型。模型返回的工具名和 JSON 参数由统一引擎校验并执行。缺少 API Key 时构造客户端直接报配置错误。

代码、合成数据和测试由本项目生成。没有使用外部商业平台素材，也没有将模型隐藏思维链写入日志。生产环境应进一步配置密钥管理、审计保留周期和网络重试策略。
