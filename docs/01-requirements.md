# 需求说明

## 输入

任务需要唯一 `task_id`、活动主题、非负预算和可解析的截止时间，可附带内容偏好或方案变体。预算和截止时间缺失时系统返回 `NEEDS_INFO`，并列出缺失字段，不调用依赖约束的工具。

## 工具

- `search_materials` 检索本地合成素材，返回内容、适用主题、成本和耗时。
- `generate_script` 根据主题与素材生成脚本草案和方案成本。
- `estimate_cost` 汇总成本、剩余预算、总耗时并同时检查截止时间。
- `save_proposal` 事务化保存最终方案，重复 `task_id` 返回已有方案 ID。

## 可靠性

执行采用多轮决策。工具可以成功、失败、部分成功或超时。失败步骤需要真实记录，已有成功步骤必须保留。预算、截止时间、最大决策轮数和最大工具调用次数均为硬约束。Real 模式需要 API Key，Mock 模式必须完整离线运行。
